# Bootstrap 模式：初始状态文档生成

你当前处于**冷启动模式**。你没有历史状态文档，需要通过 web_search 工具自主调研，建立一份有历史深度的初始状态文档。

**你必须按顺序完成以下 5 个调研方向，每个方向至少执行一次有效搜索：**

## 1. 以色列内政危机现状

- 必查：内塔尼亚胡腐败审判最新进展（目前在哪个阶段）
- 必查：本-格维尔 / 斯莫特里奇联盟当前稳定性
- 参考：以色列近期国内抗议规模

## 2. 伊朗政权稳定性现状

- 必查：里亚尔/土曼当前汇率及近期走势
- 必查：哈梅内伊健康状况及继承人传言
- 参考：IRGC 近期内部消息或人事变动

## 3. 美伊 / 以伊近期外交与军事信号（过去 90 天）

- 必查：过去 90 天内最重要的军事事件或外交节点
- 必查：美国制裁动态与对伊朗的红线表态

## 4. 伊朗核谈判状态

- 必查：JCPOA 谈判或核协议现状
- 必查：伊朗铀浓缩最新进展与 IAEA 准入状态

## 5. 地区代理人网络动态（过去 30 天）

- 必查：真主党当前战斗力状态（与2024年高峰期相比的恢复程度）、火箭炮/导弹库存
- 必查：胡塞武装红海/亚丁湾袭击频率及对以色列本土打击能力
- 必查：伊拉克什叶派民兵（伊斯兰抵抗组织）针对美军基地的近期活动
- 综合评估：伊朗是否仍能有效协调多线代理人同步行动

## 6. 美国军事态势与 CENTCOM 部署

- 必查：当前在中东的航母战斗群数量与位置
- 必查：CENTCOM 近期对伊朗目标或代理人的空袭行动规模
- 必查：美国对以色列军事行动的公开支持程度（是否共同作战、是否提供实时情报）
- 参考：美国是否在外交层面推动停火或施压任何一方降级

---

完成所有 6 个方向的调研后，调用 `submit_analysis` 工具输出初始分析结果。`updated_state_document` 字段必须包含状态文档格式规范中的**所有章节**，包括「地区代理人网络态势」和「美国军事与外交态势」，并反映你调研到的历史深度（CRI 走势部分可填写今日初始值）。
